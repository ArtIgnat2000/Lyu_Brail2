# Lyu_Brail2

# Проект «Код Брайля» — Интерактивная образовательная презентация

## 📌 О проекте

Интерактивная веб-презентация, разработанная для проведения школьного урока в **4 классе (возраст 9–10 лет)** на тему жизни Луи Брайля, принципов создания рельефно-точечного шрифта и этики взаимодействия с незрячими людьми.

Сайт работает автономно без внешних сборщиков и зависимостей (чистый HTML5 / CSS3 / Vanilla JS) и публикуется через **GitHub Pages**:

🔗 https://artignat2000.github.io/Lyu_Brail2/

---

## 🎯 Ключевые требования и педагогические принципы

1. **Контрастность для слабо затемнённого класса (WCAG AAA):**
   - Тёмные буквы (#0F172A / #1E293B) по чистому светлому фону (#F8FAFC / #FFFFFF).
   - Кнопка и горячая клавиша P включают **«Режим проектора»** (увеличенный контраст и утолщённые рамки).
   - Клавиша F — полноэкранный режим.

2. **Возрастная категория (4 класс, 9–10 лет):**
   - **Минимум сплошного текста — максимум визуальных образов:** крупные иллюстрации, карточки с тезисами, инфографика.
   - Избегать примитивных «мультяшных» клише и хаотичных эмодзи.
   - Подача через концепцию **«Лаборатория открытий: Код Брайля»** (инженерный детектив: почему военный шифр Барбье из 12 точек не прижился, а 6 точек Брайля $2^6 = 64$ идеально легли под подушечку пальца).

3. **Этика и уважение:**
   - Никакой неуместной жалости. Позитивное, равноправное общение.
   - Чёткие правила: назвать себя голосом, спросить разрешения помочь, не трогать служебную собаку-поводыря, не избегать нормальных слов («посмотри», «увидимся»).

4. **Интерактивные механики:**
   - Слайд 5: Тренажёр «Собери букву Брайля» (интерактивная сетка $2 \times 3$ с точками 1–6).
   - Слайд 6: Тактильный декодер слов в реальном времени по ГОСТу кириллического Брайля.
   - Слайд 7: Интеллектуальный командный квиз с мгновенной проверкой, звуком Web Audio API и конфетти.
   - Слайд 8: Современный Брайль в городской среде + опция 2-минутного тактильного эксперимента для класса.
