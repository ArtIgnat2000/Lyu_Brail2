# Инструкции для ИИ-агента (Arena / GitHub Copilot / Cursor)

Данный файл содержит обязательные правила и контекст для продолжения работы над проектом в новом чате/сессии.

---

## 1. Контекст проекта

- **Репозиторий:** ArtIgnat2000/Lyu_Brail2
- **Продукт:** Одностраничная интерактивная веб-презентация для школьного урока в **4 классе** (возраст учеников 9–10 лет) о Луи Брайле и рельефно-точечном шрифте.
- **Главный файл:** index.html (Vanilla HTML/CSS/JS, Web Audio API, без сторонних фреймворков и сборщиков).
- **Деплой:** GitHub Pages (ветка main, корень /).

---

## 2. Ключевые требования к дизайну и контенту

1. **Цветовая схема и контрастность (Daylight & Projector Friendly):**
   - **Строго тёмные буквы по светлому фону:** #0F172A / #1E293B на #F8FAFC / #FFFFFF.
   - Контрастность не менее 12:1 (WCAG AAA). В слабо затемнённом классе всё должно читаться с последней парты.
   - Поддержка горячих клавиш: P — переключение в сверхконтрастный режим проектора, F — полноэкранный режим.

2. **Баланс текста и визуала (для 4 класса):**
   - **Меньше текста — больше визуальных образов:** дети 9–10 лет не читают длинные абзацы.
   - Использовать крупные качественные изображения (images/), плашки, карточки с тезисами (правило 1 мысль на карточку).
   - Избегать инфантильного стиля (Comic Sans, бессистемные эмодзи в каждом слове).
   - Стиль: **«Лаборатория открытий: Код Брайля»** — инженерный научный детектив.

3. **Корректность шрифта Брайля:**
   - Алфавит закодирован по официальному кириллическому стандарту (матрица 2×3: точки 1,2,3 слева; 4,5,6 справа).

4. **Сохранение и развитие интерактивных модулей:**
   - Интерактивный конструктор символов Брайля.
   - Живой тактильный декодер слов.
   - Командный квиз с мгновенной обратной связью.

---

## 3. Чек-лист перед коммитом

- [ ] Презентация корректно отображается на ноутбуке (13–15"), проекторе/большом экране и смартфоне (узкий вертикальный экран).
- [ ] Нет сломанных путей к изображениям (все картинки лежат в images/ или в корне).
- [ ] Нет внешних тяжёлых скриптовых библиотек, мешающих автономной работе страницы.
- [ ] Код протестирован локально через python3 -m http.server 8080.
